# API-equivalence audit, 2026-09-04

Evidence behind the researchlog entry of 2026-09-04 ("Cross-model API calls
are not equivalent") and the corresponding sections in `docs/architecture/`.
Read-only audit; no runs were made and no repo code was changed.

Question (2026-09-01 meeting): do the Claude, GPT-5 Nano and Gemini calls use
the same provider and settings? Answer: no. Message roles are equivalent on
every route; provider routing, temperature, reasoning/thinking and output caps
differ per model and per era. `report.html` is the consolidated summary
(the same page as the public artifact linked from the researchlog).

## Data

| File | Content |
|---|---|
| `runs_inventory_inferred.csv` | One row per completed run JSON (6,678): `run_metadata` provider fields where present, per-run diagnostics, and `inferred_provider` for runs that predate the provider metadata (rule in `empirical_report.md` §1) |
| `grouped_by_uploader_expset_model.csv` | The inventory grouped by (uploader, experiment set, model) |
| `diag_by_model_provider.csv` | Response diagnostics per model × inferred provider, all runs |
| `diag_defector_set.csv` | Same, restricted to `negative_only_crossmodel_defectors_n5_20260825` |
| `interaction_errors.csv` | Every retry recorded in agents' `interaction_history` |
| `orphan_checkpoints.txt` | Checkpoints with no completed JSON (excluded) |

Not committed: `game_responses.csv` (175,750 individual decisions, 67 MB) and
`runs_inventory.csv` (subset of the inferred file). Both are regenerated by
the scripts below.

## Reproduce

From the repo root, with `data/json/` and `data/shared_runs/` populated
(`scripts/sync_data.sh pull`):

```bash
python scripts/audit_api_provenance_inventory.py    # -> runs_inventory*.csv, grouped_*.csv
python scripts/audit_api_provenance_diagnostics.py  # -> game_responses.csv, diag_*.csv, interaction_errors.csv
```

Both accept an optional output directory as the first argument; default is
this directory. The committed outputs were produced on 2026-09-04 from the
scratchpad copies of these scripts (identical apart from the path constants).
