# D009 — Keep permanent and random forced defection as distinct treatments

- Recorded / last verified: 2026-09-15 / 2026-09-15
- Decision status: August 24 experiment plan implemented in later matrices; interpretation narrowed by confirmation.
- Scope: eight-agent permanent defectors and two-agent per-decision random defection.
- Decision authority: August 24 slide decision and transcript attribution to Ed/Aron; implementation and later result audit are separate evidence.
- Implementation status: later completed matrices include both treatments; this record does not authorize additional runs.

## Decision and rationale

Use two or four permanent forced-zero agents in eight-agent populations and
25% or 50% seeded random forced-zero decisions in dyads as distinct stress
tests. **Explicit rationale:** introduce adverse social experience and test how
cooperation responds. Permanent defectors can also write myths; random dyad
defection is an event treatment rather than a stable social type.

## Chronology and supersession

Later confirmation does not support the broad claim that forced defectors cause
a population-wide cultural collapse. Resource loss is partly mechanical because
forced-zero decisions remove available surplus. Keep all-agent and ordinary-
agent outcomes distinct.
