- Recorded / last verified: 2026-09-15 / 2026-09-17

- Scope: injected-myth causal ablations; not ordinary endogenous myth exchange or a general removal of game history.

## Decision and rationale

First isolate whether an early or late myth changes an arriving agent's behavior
when the injected myth is the relevant inherited context. Defer the richer
rollout variants until that causal effect is understood. **Explicit rationale:**
this isolates the myth's effect on a newcomer rather than mixing it with the
source agent's gameplay conversation.
